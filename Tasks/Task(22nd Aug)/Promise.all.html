Promise combinators

Promise.all waits for the whole team.

Use Promise.all when several operations are independent but every result is required before continuing.

AsyncawaitPromise.racenew PromiseCallback

All succeed, in input order

const checks = await Promise.all([
  checkLogin(),
  checkSearch(),
  checkCheckout()
]);

console.log(checks);

The operations start together. The returned array keeps the same order as the input array, even if the third operation finishes first.

One rejection rejects the combined Promise

If any operation rejects, Promise.all rejects. Use try/catch to handle the group as one unit.

Good fit: a dashboard test that needs the user, permissions, and feature flags before asserting the page.

Why it is faster

Three one-second operations take about one second together, rather than about three seconds when each one is awaited before starting the next. Use this only when the operations do not depend on one another.

Need the fastest result instead? See Promise.race.
