JavaScript asynchronous programming

Async means “this function works with time.”

The async keyword marks a function that may wait for an operation, such as an API response, a file, or a browser action.

awaitPromise.allPromise.racenew PromiseCallback

The important rule

An async function always returns a Promise. Even when it returns a normal string, JavaScript wraps that string in a fulfilled Promise.

async function getStatus() {
  return "Test passed";
}

getStatus().then(function (message) {
  console.log(message);
});

Think of async as a promise-producing label. It does not make a slow operation magically finish sooner; it gives the function a predictable asynchronous result.

Easy mental model

  1. Call an async function.
  2. Receive a Promise immediately.
  3. Use await or .then() to read its eventual value.

In test automation, this is why a test function is often declared async: Playwright actions return promises that the test must wait for.
