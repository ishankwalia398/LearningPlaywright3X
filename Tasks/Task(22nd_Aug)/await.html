JavaScript asynchronous programming

await pauses one async function, not the browser.

await unwraps a Promise and gives you its fulfilled value. It can be used inside an async function.

Read code top to bottom

function fetchUser() {
  return Promise.resolve({ name: "Maya" });
}

async function showUser() {
  const user = await fetchUser();
  console.log(user.name);
}

showUser();

When JavaScript reaches await fetchUser(), it suspends showUser until the Promise settles. Other JavaScript work can continue. When the value arrives, the function resumes on the next line.

Sequential versus parallel

Two dependent actions should be awaited one after another. For independent actions, start both before awaiting them with Promise.all; that avoids unnecessary waiting.

const user = await getUser();
const permissions = await getPermissions(user.id);
