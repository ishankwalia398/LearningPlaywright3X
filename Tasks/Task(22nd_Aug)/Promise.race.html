Promise combinators

Promise.race gives the first finish a microphone.

Promise.race settles as soon as the first input Promise settles, whether that result is success or failure.

AsyncawaitPromise.allnew PromiseCallback

First settled wins

const response = await Promise.race([
  request("primary-server"),
  request("backup-server")
]);

console.log(response);

This is useful for a timeout or a fastest-server strategy. A fast rejection also wins, so always handle the combined Promise with try/catch.

Important detail

race does not cancel the slower operations. They continue unless you explicitly cancel them, for example with an AbortController for fetch.

Race versus all

Choose Promise.race when one result is enough. Choose Promise.all when every result is needed.

Need every check reported, even failures? Use Promise.all with appropriate error handling.
